# Серверы Xray

Добавленные серверы сохраняются сразу, независимо от включения группы мониторинга. «Сделать активным» подставляет личный outbound выбранного сервера в исходный файл Xray, сохраняя исходный `tag`. Маршруты, inbounds и остальные outbounds остаются прежними. Например, правила с `outboundTag: vless-reality` продолжают работать после смены адреса сервера.

Перед переключением панель проверяет конфигурацию настоящим Xray и доступность выбранного сервера. Затем атомарно сохраняет файлы и выполняет штатный `xkeen -restart` (`restart on` через init — запасной вариант, если команда xkeen не найдена). Панель ждёт появления нового основного процесса; отдельные процессы проверки пинга не считаются запущенной службой. Ручное и автоматическое переключение одинаково перезапускают службу, поэтому существующие соединения переподключаются. При ошибке файлы откатываются и запускается предыдущая конфигурация. Отключение браузера не прерывает уже начатую операцию.

## Пул — группа мониторинга

«Включить пул» сохраняет список проверяемых серверов и параметры мониторинга. Отдельный конфиг `07_pool.json`, служебные outbounds, балансировщик и Xray API для выбора сервера больше не создаются. Если выбран тот же сервер и outbound не изменился, включение мониторинга не перезапускает соединение.

Все серверы группы проверяются с заданной паузой после предыдущей проверки, даже если автоматическое переключение отключено. Проверки выполняются без открытой вкладки браузера.

- **Автоматическое переключение выключено:** сервер меняется вручную; результаты мониторинга продолжают обновляться.
- **Автоматическое переключение включено, «Переключаться на самый быстрый» выключено:** доступный текущий сервер сохраняется. После заданного числа отказов подряд выбирается доступный сервер с минимальным средним пингом.
- **«Переключаться на самый быстрый» включено:** доступные серверы сравниваются по среднему пингу, даже когда текущий исправен. При одинаковом среднем пинге сохраняется текущий сервер.

В поле **«Проверок для среднего пинга»** задаётся размер скользящего окна — от 1 до 60, по умолчанию 5. Во время накопления используются имеющиеся проверки. Неудачные проверки занимают место в окне, но не подставляются как нулевой пинг. Сервер с последней неудачной проверкой не выбирается, даже если у него низкое среднее по прежним результатам. Если все серверы недоступны, выбор сохраняется, проверки продолжаются. При перезапуске панели история среднего начинается заново.

Изменение списка серверов и параметров проверки не перезапускает Xray, если активный outbound остаётся прежним. При редактировании исходного активного outbound сначала отключите управление группой либо измените сервер через раздел «Серверы». Маршруты можно сохранять и применять с включённой группой.

## Перенос старой настройки

При запуске панель переносит ранее включённый пул: восстанавливает из сохранённых оригиналов `routing/api`, если старая версия их удаляла, подставляет выбранный сервер в исходный outbound и удаляет `07_pool.json` или `zz-xkeen-ui-servers-tail.json`. Перенос выполняется с проверкой и возможностью отката. Самостоятельные изменения старого управляемого файла останавливают автоматическую миграцию, чтобы не потерять их.

Отключение мониторинга сохраняет последнее выбранное подключение и библиотеку серверов. Основные данные:

- `/opt/etc/xkeen/xray-server-library.json` — библиотека серверов;
- `/opt/etc/xkeen/xray-servers.json` — состав группы, выбранный сервер и параметры проверок;
- `/opt/etc/xkeen/xray-servers-transaction.json` — временный журнал восстановления незавершённой операции.
